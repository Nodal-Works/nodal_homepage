🎬 Animation Features

Hover over any logo to see the animations:

  • Lift Effect: Logo lifts slightly and scales up
  • Enhanced Shadows: Deeper, more prominent neumorphic shadows
  • Individual Components: Each letter, disc, and ring animates independently
  • Smooth Transitions: 0.25s ease transitions for all properties
  • Dark Mode Support: Toggle dark mode to see different shadow styles

🎨 Design Details

The logo uses a neumorphic design with:

  • CSS-only implementation (no JavaScript required)
  • Responsive sizing using CSS clamp()
  • Accessibility considerations (respects prefers-reduced-motion)
  • Multi-layer shadow effects for 3D appearance
  • Optimized for both light and dark themes
